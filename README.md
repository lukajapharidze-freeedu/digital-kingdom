# Digital Kingdom

საგანმანათლებლო 3D თამაში (Three.js + Vite + TypeScript) II–IV კლასის მოსწავლეებისთვის.

## ბრძანებები

| ბრძანება | რას აკეთებს |
| --- | --- |
| `npm install` | პაკეტების დაყენება (ერთხელ) |
| `npm run dev` | თამაში ამ კომპიუტერზე: http://localhost:5173 |
| `npm run lan` | იგივე, ოღონდ ლოკალური ქსელისთვის ღია — Typing Champion-ის ქსელური რბოლისთვის |
| `npm run build` | საბოლოო ვერსიის აწყობა `dist/`-ში (ამას იყენებს Vercel) |
| `npm run preview` | აწყობილი ვერსიის ნახვა |

## Typing Champion — ბეჭდვის რბოლა ქსელში (2–4 მოთამაშე)

ბრაუზერებს ერთმანეთთან პირდაპირ კავშირი არ შეუძლიათ, ამიტომ ერთი კომპიუტერი მასპინძლობს:

1. ყველა კომპიუტერი ერთ Wi-Fi / ლოკალურ ქსელში უნდა იყოს.
2. მასპინძელ კომპიუტერზე გაუშვით:
   ```bash
   npm run lan
   ```
   ტერმინალში გამოჩნდება `Network: http://192.168.x.x:5173/` — ეს არის მისამართი სხვებისთვის.
   (Windows-მა შეიძლება Firewall-ის ნებართვა იკითხოს — დააჭირეთ „Allow“.)
3. მასპინძელი: სამჭედლო → **Typing Champion** (ერთხელ გასახსნელად 6 📘) → სახელი → „ოთახის შექმნა“. ეკრანზე ჩნდება 4-ნიშნა კოდი და ქსელის მისამართიც.
4. დანარჩენები ბრაუზერში ხსნიან იმ `http://192.168.x.x:5173/` მისამართს → სამჭედლო → Typing Champion → სახელი + კოდი → „შესვლა კოდით“.
5. მასპინძელი ირჩევს ეტაპების რაოდენობას (3–5) და იწყებს რბოლას.

წესები: პირველ ეტაპზე 15 სიტყვაა, ყოველ შემდეგზე +5. მრბოლელი ყოველ ეტაპზე იცვლება
(ფეხით → მანქანა → მოტოციკლი → რაკეტა → მფრინავი თეფში). ყოველი სიტყვა კიბის ერთი საფეხურია.
პირველი ფინიშის შემდეგ ჩაირთვება წამზომი და დანარჩენებს 10 წამი აქვთ. ეტაპის ქულა = გავლილი საფეხურები
(1 სიტყვა = 1 ქულა) + ფინიშის ბონუსი (1-ლი 5, მე-2 3, მე-3 2, მე-4 1); გამარჯვებულია ქულების ჯამით.
თამაშის გახსნა სამჭედლოში 6 📘 ღირს.
ბეჭდვა შეიძლება ქართული განლაგებითაც და ინგლისურითაც (ასოები ქართული სტანდარტული განლაგებით: T = თ, Shift-ით).

ტექნიკურად: რელე არის Vite-ის პლაგინი [`server/typingChampionRelay.mjs`](server/typingChampionRelay.mjs), რომელიც
dev/preview სერვერზე `/typing-champion-ws` მისამართზე WebSocket-ს ხსნის (დამატებითი npm პაკეტის გარეშე).
Vercel-ზე რელე არ არის: დანარჩენი თამაში ჩვეულებრივ მუშაობს, Typing Champion კი გეტყვით, რომ საჭიროა `npm run lan`.
